# Демо: защищённый ИИ-помощник руководителя

## Запуск

```
npm install        # один раз
npm start          # http://localhost:3000
npm test           # 458 проверок, должно закончиться «всё на месте»
npm run reset      # сбросить демо-состояние (журнал, приглашения, пересылки, записи)
```

Нужен Node 20.12 или новее. На Node 22 можно запускать без `tsx`: `npm run test:node22`.
Настройки — в `.env` (образец в `.env.example`). Ключ ИИ-модели не обязателен: без него работают заготовки.

## Оформление

Оформление взято из макета PHOTOPRINT (`PHOTOPRINT-glavnaya-otkryto.svg`): шапка с плашками, крупные числа, градиентные карточки, помощник справа, тёмная полоса «В работе» снизу. Весь внешний вид — в одном файле `public/style.css`, настройки (цвета, радиусы, ширина помощника, шрифт) в блоке `:root` в начале файла. Если макет изменится, меняется этот файл; логика и тесты не трогаются.
Шрифт Manrope (лицензия SIL OFL) лежит в `public/fonts/`, интернет при показе не нужен.

## Роли

Переключатель справа вверху. По умолчанию директор (Алина К.).
Директор видит всё. Менеджер (Сергей Л.) — только своё. Зам по технологиям (Иван), зам по развитию (Дмитрий), помощник (Ольга) — каждому своё по `data/access.json`, календарю и приглашениям.

## Сценарий показа (10 минут)

1. **Главная** (директор). Крупные числа: встречи сегодня, просрочено, не успеваем, без исполнителя. Нажать «Просрочено» → список → «основание: протокол, 01:29» → открылся протокол на нужной секунде записи. Это дорога «обзор → задача → пункт протокола → секунда записи».
2. **Протокол.** Нажать на время у решения «берём второго поставщика» — запись играет с 03:04. Вопрос про приёмку работ с плашкой «требует уточнения»: в записи не решён.
3. **Задачи из решений** (внизу протокола): «Поставить все отмеченные». Задачи идут в Битрикс (заглушка). Нажать дважды — вторая не создаётся.
4. **Задачи → Обмен с Битриксом.** Переключатель «ошибка 503» → подтвердить предложение → «Ждёт Битрикса», повтор идёт сам → переключить на «успех» → задача доставлена.
5. **Документы.** Один и тот же запрос под директором и под менеджером — разные ответы. Письмо поставщика: красная карточка «скрытая команда», не выполнена. «Открыть» показывает строку.
6. **Защита.** Менеджер ищет «оклад премиальная» — «в доступных вам документах этого нет». Админ-контроль: директор находит.
7. **Встречи.** Слева три ближайшие встречи, справа календарь недели («Раскрыть» — календарь на весь экран, «+ Встреча» — назначить). Нажмите на встречу «Созвать по переплёту»: откроется окно со списком «что подготовить», протоколом предыдущей встречи (к чему пришли, кто за что отвечает, идеи без ответственного, вопросы без решения) и документами по теме; «Собрать документы на встречу» собирает пакет, «Скачать одним файлом» отдаёт его. «Добавить людей» (видно только в раскрытом окне): люди из системы и гости, которых в системе нет; приглашение уходит в Битрикс и/или мессенджер (заглушки) только после нажатия кнопки. Плашка «Протоколы встреч» открывает протоколы всех встреч. Под Ольгой приглашение внизу, «Добавить в мой ИИ» открывает доступ.
7а. **Задачи.** Сверху большая плашка «Задачи на сегодня» (срок сегодня и просроченные), «+ Задача» ставит задачу исполнителю прямо в его Битрикс. «Выполнена» закрывает задачу (в Битриксе тоже), просит описать, как выполняли; закрытые попадают в светло-зелёное окно «Выполнено». «Команда»: выберите сотрудника в справочнике Битрикса, «Добавить в мою систему», он подключён и появляется в исполнителях. «База знаний»: из закрытой задачи получается черновик, руководитель правит название, теги и шаги и публикует; все ищут по тегу и словам (и через чат помощника: «Как заказать бумагу?»). Переключатель «Агент ставит задачи после встречи сам»: после записи встречи агент сам ставит в Битрикс каждому исполнителю задачи, где названы исполнитель и срок; остальное оставляет руководителю.
8. **Пересылка.** В окне документа «Переслать коллеге»; получатель сам принимает; отправитель может отозвать.
9. **Запись встречи** (`Встречи → Записать встречу сейчас`). С микрофоном — настоящая запись и локальное распознавание (Chrome). Во время записи на экране всегда плашка «идёт запись». «Проверить без микрофона» — 30 секунд тестовой записи до протокола.
10. **Помощник справа** отвечает на «Что просрочено?», «Кто перегружен?», «Что решили на планёрке?» данными системы и ищет по документам с файлом, строкой и цитатой. **Полоса «В работе»** показывает то, что агент делает сейчас (например, повтор отправки в Битрикс) с кнопкой «Прервать».
11. **След действий.** «Только отказы агента»: скрытая команда, нет прав, нет данных.

## Что настоящее, что показано

| Настоящее | Показано (режим демонстрации) |
|---|---|
| Права и фильтр до поиска, сканер скрытых команд, проверка цитат и номеров кусков, безопасный повтор, журнал, приглашения и пересылка, запись звука в браузере | Документы, люди, расшифровки; пункты протокола и связи решений («дрейф») — заготовки вместо модели; Битрикс — заглушка; звук демо-встреч — синтетические сигналы; отправка писем наружу — не делается вовсе |

На показе говорить так: «логика безопасности написана по-настоящему, данные синтетические, модель подключается одной настройкой».

## Где что лежит

- `src/` — код. `access.ts`, `injection.ts`, `load.ts`, `model.ts` — защита, их логику не менять.
- `public/` — страницы; весь CSS в `public/style.css`, значения цветов и размеров — в `:root`.
- `data/` — исходные данные. Состояние демо: `data/trail.jsonl` (журнал, открывается блокнотом), `data/meetings-state.json`, `data/shares.json`, `data/bitrix-mock.json`, папка `meetings/` (звук, расшифровка, протокол). Всё это стирает `npm run reset`.
- `tests/` — проверки: `evals.ts` (защита и базовые) и `demo-evals.ts` (пересылка, протокол→задачи, звук, запись, обзор, журнал).

## Ограничения демо

- Авторизации нет: роль выбирается в интерфейсе, сервер доверяет ей. Слушает только `127.0.0.1`.
- Состояние в файлах, базы нет. Журнал не шифруется.
- Загруженные файлы живут в памяти сервера до перезапуска.
- Распознавание речи работает только в браузере с локальной моделью русского (Chrome); иначе пишется звук и метки, расшифровка позже.


## Новое: документы, подтверждение задач, кнопки «Назад»

- **Назад / Выйти** есть на каждой странице; на экране записи кнопка называется «Выйти» и предупреждает, если запись идёт.
- **Документы**: пять равных плиток (собрать на встречу, поиск на ноутбуке, анализ и суть, сравнение, поиск с подсветкой). Каждая открывает окно: пояснение, поле для ИИ с подсказкой, ответ с подсветкой слов, и там же можно уточнять («короче», «только цифры», «ещё штраф»). Идущая задача видна в «В работе».
- **Задачи после встречи** по умолчанию уходят руководителю на подтверждение; в Битрикс они попадают только после кнопки. Режим «без подтверждения» включается переключателем на странице «Задачи».
- **База знаний**: опубликованная запись лежит в общей папке `knowledge/`, её видят все сотрудники (подпись на записи).
- Разбор документов идёт по тексту, без языковой модели; это честно написано в окне.

- **Маршрут** (вкладка): схема «откуда → проверка → куда уходит → кто видит». Числа берутся из журнала действий. Нажмите на маршрут или плашку: путь подсвечивается, остальное тускнеет. У каждого маршрута написано, что едет и что не едет. Пунктир значит, что по пути пока ничего не ходило.
- **Решения** (вкладка): сверху всё, что агент подготовил и не отправил без вашего нажатия: приглашение на предложенную встречу, ответ на письмо поставщика, задачи после встречи. У каждой карточки видно, кому и что уйдёт дословно, есть «Отправить» и «Отклонить». Ниже раздел «Защита: найденные скрытые команды» (атаки в документах больше не лежат в «Без вас не двинется»), затем решения со встреч и дрейф. Отправка имитируется.

## Показать без localhost: один HTML-файл

Команда `npm run build:html` собирает файл `dist/photoprint-demo.html` (около 1 МБ). Внутри интерфейс, шрифты, данные и весь код «сервера», который работает прямо в браузере. Интернет, Node и запуск не нужны: файл открывается двойным щелчком в Chrome или Safari и работает так же, как версия на localhost.

- Данные живут в браузере и переживают перезагрузку. Сброс до чистого состояния: добавьте к адресу `#/reset` (или откройте файл в новом окне инкогнито).
- Работает всё: документы, задачи ИИ, встречи, решения и подтверждения, маршрут, журнал, защита, запись с микрофона. Битрикс и мессенджер по-прежнему имитация.
- Отличие одно: настоящая модель (ключ Anthropic) из файла не подключается, чтобы ключ не лежал в открытом виде. Ответы без модели, как и сейчас.
- Файл можно положить на флешку, отправить в чат или выложить на любой хостинг статических страниц.
- **Настройки** (вкладка): слева подключения (Битрикс, Gmail, Календарь, Telegram, модель, микрофон) со статусом, справа права: что можно видеть, что можно делать только с подтверждением, чего нельзя никогда. Внизу правила безопасности, в том числе срок действия пересылки (правило для боевой версии).

## Роль и показ прав

В шапке только профиль того, кто вошёл: имя и роль. Выбора человека в интерфейсе нет. Чтобы на защите показать, как работают права, откройте систему от имени другого человека через адрес: добавьте `?as=sergey` (менеджер), `?as=ivan` (заместитель по технике), `?as=olga` (помощник). В файле `photoprint-demo.html` адрес выглядит так: `photoprint-demo.html#/?as=sergey`. Руководитель по умолчанию: `?as=alina` (отображается как «Сергей К.»).
